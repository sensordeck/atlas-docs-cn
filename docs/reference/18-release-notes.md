# 发布说明

本页汇总了 Atlas Runtime Governance™ 的主要版本发布说明。

发布说明描述产品演进、新功能、兼容性和重要变更。

项目特定的定制化内容另行记录，不包含在公开发布说明中。

---

# 版本规则

Atlas 采用语义化版本控制。

```text
主版本号.次版本号.补丁版本号
```

示例：

```text
v1.0.0
```

其中：

- **主版本号** — 架构或兼容性变更
- **次版本号** — 新功能和能力
- **补丁版本号** — 缺陷修复和维护改进

# 亮点

版本 1.0 引入了首个完整的机器人运行时治理平台。

主要功能包括：

- 运行时数据集生命周期
- 运行时表面框架
- 运行时观测
- 运行时证据包
- 运行时执行失败（REF）
- 历史运行时治理资产（历史 RGA）
- 调查上下文
- 调查等级候选
- Sensor Engagement Pack
- Assist Vault
- 运行时治理指标
- 试点到生产部署框架

- 滚动缓冲区
- 数据集锁定

# 调查工作流

引入：

- 运行时执行失败（REF）
- 证据包
- 历史 RGA 召回
- 调查上下文
- 调查等级候选
- 调查结果（IR）
- 经验总结（LL）

Atlas 标准化运行时调查工作流，但不判定根本原因或责任归属。

# 兼容性

Atlas 设计为与现有机器人系统集成。

典型集成包括：

- Linux
- 基于 ROS 的系统
- 自定义运行时平台
- 车队管理平台
- 企业工单系统

---

# 已知限制

Atlas 明确**不**：

- 自动判定根本原因
- 划分责任归属
- 替代车队管理系统
- 替代工单系统
- 替代传感器驱动
- 替代机器人应用
- 替代安全认证

Atlas 专注于运行时治理。
