# 下载

## 概述

Atlas Runtime Governance™ 通过企业部署项目交付，而非公开软件下载。

每次客户部署均根据以下内容进行定制：

- 产品范围
- 运行时表面覆盖范围
- 部署环境
- 调查工作流
- 集成需求

可交付成果取决于项目范围和商业协议。

---

# 典型可交付成果

标准 Atlas 部署可能包括以下可交付成果。

## 运行时组件

- Atlas Agent
- 运行时适配器
- 运行时表面配置
- 运行时数据集策略
- 导出配置

---

## 调查组件

- 证据包
- 历史 RGA 仓库
- 调查工作流
- 调查上下文
- 调查等级候选
- Sensor Engagement Pack
- Assist Vault（可选）

---

## 文档

典型文档包括：

- 部署指南
- 运行时表面映射
- 调查工作流
- 操作指南
- 管理员指南
- 培训材料

---

## 配置

项目特定配置可能包括：

- 运行时表面注册表
- 适配器配置
- 运行时策略
- 保留策略
- 导出策略
- 授权策略

# 项目可交付成果

根据项目的不同，Atlas 可能提供：

- 安装包
- 部署包
- 配置包
- 历史 RGA 初始化包
- 运行时画像包
- 试点验收报告
- 生产就绪报告

可交付成果在项目工作说明书（SOW）中定义。

---

# 软件更新

软件更新根据客户支持协议提供。

更新可能包括：

- 缺陷修复
- 性能改进
- 新运行时表面支持
- 调查工作流改进
- 新运行时画像模板

项目特定的定制化内容另行管理。

---

# 文档更新

文档随主要产品版本一起更新。

客户可能收到：

- 更新后的部署指南
- 更新后的运行时表面定义
- 更新后的调查工作流
- 更新后的运行时画像模板
- 更新后的历史 RGA 模板
